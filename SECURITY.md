# Security policy / 安全漏洞报告

This repository relates to financial research and may process sensitive account, strategy or model information. **Do not publish exploit details, credentials or live-account data in issues or pull requests.**

Preferred channel: use this repository's GitHub **Security → Report a vulnerability** / private vulnerability reporting feature **if enabled**. If that feature is not enabled, contact the maintainer via an established private channel to request secure reporting instructions, without posting exploit details publicly. A dedicated security inbox is not yet configured; do not assume a public issue is private.

When reporting, provide a minimal reproducible description, affected versions, severity, and a sanitized demonstration using fake credentials and test data. Do not run live orders, probe third-party systems, or access other users' information.

See the repository's `AGENTS.md` and any architecture/security documents for engineering safeguards. No support SLA or disclosure deadline is promised by this policy.
